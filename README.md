# Estudos de FastAPI

Este repositório faz parte do meu Plano de Desenvolvimento Individual (PDI) e tem como objetivo registrar meus estudos e minha evolução no aprendizado de FastAPI.

O foco é compreender os fundamentos do desenvolvimento de APIs REST, explorar boas práticas e adquirir conhecimentos que possam ser aplicados futuramente em outros projetos.

## Conteúdo de referência

Os estudos são baseados no curso gratuito **FastAPI do Zero**, desenvolvido por Eduardo Mendes (Dunossauro).

🔗 [FastAPI do Zero — Documentação do curso](https://fastapidozero.dunossauro.com/estavel/)

## Objetivos

- Aprender os fundamentos do FastAPI.
- Desenvolver APIs utilizando Python e FastAPI.
- Trabalhar com rotas, requisições e respostas HTTP.
- Utilizar Pydantic para validação de dados.
- Integrar APIs com bancos de dados.
- Implementar autenticação e autorização.
- Desenvolver testes automatizados.
- Aplicar os conhecimentos adquiridos em projetos futuros.

## ️Tecnologias
